# To-Do App

A responsive React To-Do app for managing daily tasks — add, edit, complete,
and delete tasks with status tracking, filtering, and Local Storage persistence.

## Features Implemented
- Add new tasks
- Mark tasks as completed
- Edit existing tasks
- Delete tasks
- Display task status (Completed/Pending)
- Task filtering (All / Completed / Pending)
- Local Storage integration (tasks persist after refresh)
- Responsive design (mobile & desktop)

## Technologies Used
- React (via CDN — `React.createElement`, no JSX/build tool)
- JavaScript ES6+ (arrow functions, destructuring, spread operator, `.map()`/`.filter()`)
- HTML5 & CSS3

## Setup Instructions
No installation required.
1. Clone or download this folder
2. Open `index.html` directly in your browser
   *(or right-click → "Open with Live Server" in VS Code)*
